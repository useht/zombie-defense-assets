# zombie-defense-assets

좀비 디펜스 게임이 쓰는 자산 묶음입니다. 게임이 공개 CDN(jsDelivr)에서 받아 쓰도록 둔 사본입니다.

- 이 묶음에는 재배포가 허락된 라이선스(CC0 1.0 · CC BY 4.0 · MIT)의 자산만 들어 있습니다.
- **자산별 라이선스·저작자·출처·고친 점은 [THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt) 를 보십시오.** CC BY 자산을 다시 쓸 때는 그 고지대로 표시해야 합니다.
- 이 저장소의 파일에는 각 원 라이선스 밖의 제한을 두지 않습니다.
- `files.json` 은 게임이 이 묶음에서 받을 파일 목록(경로·크기·SHA-256)입니다.
